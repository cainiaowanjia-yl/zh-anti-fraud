# 大白话模式

用户说 ELI5、ELT5、大白话、像朋友一样讲明白时使用。初入社会的人对术语陌生时，也可以用这种口吻。按成年人日常聊天来写，用常见词和短句。需要生活例子时选一个，点到为止。

1. 先用一句话讲事情最大的变化。比如“他让你去时说有人能定，等你花了钱，他才说只能给你一个电话号码”。
2. 用户说“从头讲整件事”时，按先后逐段写。每段回答“对方说了什么”“你做了什么”“当时在哪一步可以先停”。关键金额、物品、承诺、谁直接说的及哪些事还待核对要保留。两段先后不明确时分开讲。
3. 把术语换成可以问出口的话。“核授权”变成“谁能做主，让他本人说一句”。“防止受沉没成本影响”变成“如果没花过前面那笔钱，这个新机会还值得花钱吗”。“止损”变成“先把手上还没给出去的钱、东西和权限守住”。
4. 用“你说你付了”“他当时说会给”“这条还说不准”等日常说法保留证据边界。拒绝把私人索求、口头许诺、实际收到的钱混作一笔。分开谁帮过忙、谁说得太满、谁后来改变了条件。
5. 问“如果我没停会怎样”时，从对方已经做过的事挑两三种可能，用“如果他又……，你就……”直接讲。正在发生的危险先给保护自己的办法。结尾给一句能直接回复的话。

遇到复杂案件，先按[做局深拆](deep-analysis.md)检查事实和判断，再用这份指引讲出来。“大白话”改变表达的方式。“简单说”和“把整件事从头讲”分别按用户要求控制长度。需要典故时，用两句讲清原故事以及和眼前哪一步相像。[有原文出处的典故](allusions.md)
