# 海外与跨境骗术索引

资料核对至 **2026-11-21**。下列是各地公开资料中的常见机制、当地叫法和具体变种。地区说明来源或哪种服务被冒用。人在甲地、钱经乙地支付、对方自称丙地机关时，把三个地点分开。紧急风险找事发地或人员所在地警方，款项先找实际办理支付的机构，涉领保可联系相关使领馆。案件涉及多地时向警方说明。处理同一事件时可同时查[国内及生活类索引](patterns.md)和[止损指引](response.md)。[国际刑警组织全球金融欺诈评估](https://www.interpol.int/en/News-and-Events/News/2026/INTERPOL-report-warns-of-increasingly-sophisticated-global-financial-fraud-threat) · [国际刑警组织求助说明](https://www.interpol.int/en/What-you-can-do/If-you-need-help)

## 冒充公职、银行、熟人与上门取物

| 地区与叫法 | 看见什么，以及怎么核对 |
|---|---|
| 香港「假冒官员」与电话转驳 | 对方称个人资料被用于登记储值卡，接着把来电转给自称公安的人。挂断后从独立官方渠道核对；同一次电话转接仍是同一消息链。[警务处案例](https://www.adcc.gov.hk/zh-hk/alerts-detail/alerts-1933439595465740289.html) |
| 日本「オレオレ詐欺」 | 自称亲属出事故，催交和解款。用自己原先保存的号码联系亲友；确有事故再核负责机构和付款渠道。[日本警察厅手法一览](https://www.npa.go.jp/bureau/safetylife/sos47/case/) |
| 日本「還付金詐欺」 | 声称有税费或社保款可退，要求现场操作 ATM。回实际主管机关查退款有没有办理记录。[日本警察厅手法一览](https://www.npa.go.jp/bureau/safetylife/sos47/case/) |
| 韩国 보이스피싱 与 미끼전화 | 假检警、假法院公文，或声称要送从未申办的信用卡，引导拨另一个号码。自行找法院、发卡行或政府反诈入口核查。[韩国联合应对门户](https://www.counterscam112.go.kr/campaign/index.html) |
| 韩国 대환대출 与 스미싱 | 假低息转贷要求先清偿旧贷，或把钓鱼链接伪装成婚帖、丧帖、罚单。通过原贷款行核债务，从已知渠道核实对应通知。[韩国联合应对门户](https://www.counterscam112.go.kr/campaign/index.html) |
| 新加坡 Fake Friend Call | 陌生号码让用户猜自己是谁，随后以急事请求借款。回拨熟人原有号码，问清借款是否本人提出。[ScamShield](https://www.scamshield.gov.sg/i-want-protection-from-scams/learn-to-recognise-scams/fake-friend-call-scams/) |
| 新加坡假电信客服转接警方或金融管理局 | 假客服称有异常订购，经同一电话转接后索钱、珠宝或名表。自行打开运营商账户查实际订单，按所称机构的官方入口核身份。[2026-10-29 新加坡警方通报](https://www.police.gov.sg/Media-Hub/News/2026/10/20261029_police_advisory_on_scams_involving_the_impersonation_of_simba_staff) |
| 印度 Digital Arrest（数字逮捕） | 自称调查人员以疑似涉案为由要求持续视频、服从监控或付款。中断对方指令，联系亲友和当地警方，从真实机关入口核实。[印度中央后备警察部队资料](https://crpf.mha.gov.in/Upload/MediaGallery/SPL_EDITION_CYBERBYTE_OCTOBER_2026_ENGLISH.pdf) |
| 英国 Courier fraud（假银行或警方派人取卡） | 对方称卡有异常，派人上门取卡、现金或贵重物品。自行拨卡背银行电话。取物者仍在现场时先保护人身安全。[英国 Report Fraud](https://www.reportfraud.police.uk/courier-fraud/) |
| 法国 Faux numéro d’opposition bancaire | 短信报异常扣款，留“紧急挂失”电话。自行通过银行已知应用、卡背号码核实。[法国公共网络安全平台](https://www.cybermalveillance.gouv.fr/tous-nos-contenus/actualites/lhameconnage-au-faux-numero-dopposition-bancaire) |
| 荷兰 Bankhelpdeskfraude、babbeltruc | 有人自称银行防诈部门或侦探，要到家里取卡或财物。用已知银行及警方渠道核实，避免把卡交给来访者。[荷兰警方预警](https://www.politie.nl/informatie/wat-is-telefonische-helpdeskfraude-bank.html) · [2026年11月案例](https://www.politie.nl/nieuws/2026/november/18/04-nepagent-spijkerboorweg-haarlem.html) |
| 澳大利亚假银行“保护账户”、假税务机构或 myGov | 核对实际账单及政府账号收件箱。有来电、自称工作人员、交易记录截图时，仍可从自己已知的官方渠道回拨。[Scamwatch 银行仿冒](https://www.scamwatch.gov.au/about-us/news-and-alerts/scam-alert-scammers-impersonating-banks-in-text-messages-phone-calls-and-emails) · [ATO 和 myGov 仿冒](https://www.scamwatch.gov.au/about-us/news-and-alerts/australian-taxation-office-ato-and-mygov-impersonation-scams) |
| 跨地区 AI 仿声、换脸、伪造机构影像 | 同时核本人及其要求。声称亲人有危险时，通过保存的号码、家属或有关机构独立核平安。是否为 AI 生成留给有依据的鉴定。[国际刑警组织 2026 年评估](https://www.interpol.int/en/News-and-Events/News/2026/INTERPOL-report-warns-of-increasingly-sophisticated-global-financial-fraud-threat) |

## 商务、支付、贷款与投资

| 地区与叫法 | 看见什么，以及怎么核对 |
|---|---|
| 台湾地区「三方诈欺」 | 账户确有进账，但付款人与下单人或退款收款人对不上。先暂停发货和自行退款，款项留在账户内。从原平台核对订单，让银行或平台确认该笔交易该如何处理。[台湾地区刑事警察局](https://www.cib.npa.gov.tw/ch/app/news/view?id=1887&module=news&serno=d0127100-22d4-430c-bf1d-62045ba98118) |
| 美国 Fake check / overpayment | 支票额度超过货款或兼职报酬，要求把差额退回。余额暂时显示可用时，先向银行确认票款是否已最终入账。[FTC 假支票指南](https://consumer.ftc.gov/articles/how-spot-avoid-and-report-fake-check-scams) |
| 美国 Mortgage closing scam（产权交割改电汇） | 房产成交前收到临时改汇款账户的邮件。按事先保存的电话向产权、托管或律师方核对。相同机制也出现在老板或供应商邮件里。[美国 CFPB 提示](https://www.consumerfinance.gov/owning-a-home/beware-mortgage-closing-scams/) · [FBI 商务邮件诈骗](https://www.ic3.gov/CrimeInfo/BEC) |
| 法国私下换汇假转账或假现金 | 有假凭证、资金冻结或收到假钞的风险。走有资质的换汇渠道，独立查看实际交易状态。[驻法国使领馆提示](https://fr.china-embassy.gov.cn/chn/zgzfg/zgsg/lsqwc/202608/t20260825_12010188.htm) |
| 巴西 Golpe do Pix errado（Pix“转错钱”） | 对方声称 Pix 转错，请用户退到另一账户。先在自家银行查实，确需返还时向银行核实该笔交易的正式退款功能。付款受骗可向自己的金融机构询问 MED 的适用性。[巴西央行 Pix 安全页](https://www.bcb.gov.br/estabilidadefinanceira/pix-seguranca) |
| 印度尼西亚 Salah transfer（转错账或非法贷款） | 账户出现来路不明的到账，随后有人催向指定账户退款或索还一笔未申请的贷款。联系银行查明来源，保留现有记录。[印尼金融服务管理局案例](https://ojk.go.id/id/berita-dan-kegiatan/publikasi/Documents/Pages/Siaran-Pers-KOJK-Kalimantan-Tengah-SJK-Kalimantan-Tengah-Terjaga-Stabil-dan-Didukung-Kinerja-Intermediasi-yang-Semakin-Kuat/SP%20KOJK%20Kalteng%20Sektor%20Jasa%20Keuangan%20Kalimantan%20Tengah%20Terjaga%20Stabil%20dan%20Didukung%20Kinerja%20Intermediasi%20yang%20Semakin%20Kuat.pdf) |
| 墨西哥 Suplantación de instituciones financieras | 冒用真正金融机构名称、图标和登记信息，承诺放款并索款。通过 CONDUSEF 的金融服务登记及真实机构的联系方式核对承诺、实际域名与收款主体。[墨西哥 CONDUSEF](https://www.condusef.gob.mx/index.php?idc=2718&idcat=3&p=contenido) |
| 澳大利亚假债券、迪拜仿冒持牌机构 | 假广告可使用真实持牌机构的名字。分别查真实机构、所售产品、发来链接的域名、收款主体及来信人权限。[Scamwatch 债券骗局](https://www.scamwatch.gov.au/about-us/news-and-alerts/scam-alert-investment-bonds-scam) · [迪拜 DFSA 假冒案例](https://www.dfsa.ae/alerts/dfsa-authorised-firm-impersonated-xtb-mena-limited) |
| 跨地区 Romance investment / Pig butchering | 在交友中取得信任，再推荐看似能盈利的投资。查钱实际到哪里、利润是否只有平台数字。遇到提现先缴费，暂停新增付款。[FTC 投资风险说明](https://consumer.ftc.gov/consumer-alerts/2026/04/people-losing-big-investment-scams-learn-how-spot-and-avoid-them) |
| 跨地区假交易所、假流动性挖矿、假加密资产追损 | 对方要求钱包授权、交助记词、转账或先付追回费。查授权记录和交易状态，联系实际使用的平台。密码、助记词和可签名材料留在自己手中。[IC3 假交易所](https://www.ic3.gov/PSA/2024/PSA240801) · [IC3 假挖矿警示](https://www.ic3.gov/PSA/2022/PSA220721) · [IC3 二次追损](https://www.ic3.gov/PSA/2023/psa230811) |
| 跨地区 Advance-fee fraud（预付费骗局） | 陌生人承诺继承款、补助或巨额回报，要求先付手续费、税或保证金。自行联系真实主管部门、银行或相关事项的正式受理人。归类依据是索款动作，与来信人自称哪里人无关。[尼日利亚 EFCC 案例汇编](https://www.efcc.gov.ng/efcc/images/pdfs/RED_ALERT_ON_SCAM.pdf) |

## 求职、旅行、住房与数字账户

| 地区与叫法 | 看见什么，以及怎么核对 |
|---|---|
| 加拿大、英国假工作或签证“付费包批” | 社交媒体中介索取材料和费用，保证岗位或签证获批。从雇主官网核岗位，再查目的地移民机关的申请流程。[加拿大移民部门](https://www.canada.ca/en/immigration-refugees-citizenship/services/admissibility-enforcement/consequences-unauthorized-work.html) · [英国 Home Office](https://www.gov.uk/government/publications/frauds-tricks-and-scams/fraud-tricks-and-scams) |
| 南非假公职录用、假政府招标 | 通知带机构标识却要先交可退背景调查费，或出现从非公开渠道发来的采购机会。从部门正式招录或采购入口核文件、岗位及收费规定。[南非卫生部门](https://www.gov.za/news/media-statements/health-warns-public-job-scam-11-jul-2023) · [南非就业与劳工部](https://www.labour.gov.za/Media-Desk/Media-Alerts/Pages/Public-warning--beware-of-fraudulent-tender-advertisements-and-job-opportunities.aspx) |
| 美国 Reshipping 与 Money mule（代收转寄、个人账户过账） | 居家兼职内容是重寄来路不明的货、收款后再转。暂停交运和转款，核雇主、货权与款项来源。已收货或进账时向平台、银行或警方咨询处理。[FTC 代寄包裹](https://consumer.ftc.gov/consumer-alerts/2025/12/can-you-unbox-signs-reshipping-scam) · [FBI 钱骡说明](https://www.fbi.gov/how-we-can-help-you/common-frauds-and-scams/money-mules) |
| 跨境高薪招聘与强迫从事诈骗 | 雇主、工作地点或入境用途无法核实，入境后有人控制证件、通信或行动。若人身受到控制，先在安全可行时联系当地应急机关、使领馆或可信联系人。家属可向相关机构提供最后联系和所在地线索。[国际刑警组织专题](https://www.interpol.int/en/News-and-Events/News/2025/Growing-threat-of-transnational-scam-centres-highlighted-at-INTERPOL-General-Assembly) |
| 欧盟 ETIAS、英国 ETA 假旅行授权站点 | 第三方网页冒用官方外观、承诺加急或提前办理。直接查目的地机关，按出行日期核是否需要、何时开放及费用。[欧盟官网仿冒警示](https://travel-europe.europa.eu/en/etias/about-etias/news-corner/Emergence-of-unofficial-ETIAS-websites) · [英国 ETA 官方入口](https://www.gov.uk/eta/apply) |
| 德国与西班牙假房源或假度假订单 | 相同照片搭配不同联系人，出租人要求先付看房费或绕开平台支付。独立核出租授权、实地或平台房源、款项去处。[德国警察预防服务](https://www.polizei-beratung.de/aktuelles/detailansicht/vorsicht-vor-betrug-bei-der-wohnungssuche/) · [西班牙 INCIBE 骗术指南](https://www.incibe.es/sites/default/files/docs/guia_fraudes/guia-fraudes-online.pdf) |
| 香港演唱会、欧洲赛事假票 | 群聊声称有内部票，电子票图或转账记录看起来齐全。回主办方公布的售票、退票或转售入口核验该场规则。[香港警务处票务资料](https://www.police.gov.hk/offbeat120/scam/what-is-concert-ticket-scam.html) · [UEFA 官方售票示例](https://www.uefa.com/news-media/news/02a3-2028ddb9cac9-90649706d3cc-1000--ticket-sales-for-general-public-open-for-2026-uefa-club-com/) |
| 荷兰旅游假便衣警察 | 在街上以查护照、假钞等理由要求交钱包。处境允许时找有人值守的公共处，从官方入口联系警方核实。[驻荷兰使馆旅游手册，第11页](https://nl.china-embassy.gov.cn/ls/202604/P020260227791571934004.pdf) |
| 英国假 DVSA 停车罚款、新西兰假通行费或驾照续期 | 短信说不立即支付将产生罚款，附付款链接。去原停车机构或当地交通机构页面核账单。[英国 DVSA](https://www.gov.uk/government/news/dvsa-issues-warning-about-parking-fine-scam-text-messages) · [新西兰 NZTA](https://nzta.govt.nz/do-it-online/scams/example-scams/text-message-scams) |
| 美国停车缴费与陌生包裹二维码（QR phishing / Quishing） | 二维码可能覆盖正规牌子，陌生包裹二维码也可能通向假退货页。用现有停车应用、运营商网页或原订单核对。[FTC 停车二维码](https://consumer.ftc.gov/consumer-alerts/2026/09/see-qr-code-parked-somewhere-dont-scan-ityet) · [FTC 未订购包裹](https://consumer.ftc.gov/consumer-alerts/2025/01/scam-alert-qr-code-unexpected-package) |
| 美国 SIM swap（被冒名换卡或转号） | 手机突然失去服务并有自己未发起的换卡、转号或登录提示。用另一台可信设备联系运营商，同时查金融和主邮箱账户。[FTC 指引](https://consumer.ftc.gov/consumer-alerts/2019/10/sim-swap-scams-how-protect-yourself) |
| 加拿大 Subscription trap（试用变自动续费） | 核对试用时披露的续费条款、付款授权、实际扣款和是否能按承诺取消。保存取消凭据，通过原发卡行或商户处理未授权扣款。[加拿大竞争局](https://competition-bureau.canada.ca/en/fraud-and-scams/tips-and-advice/subscription-traps) |

## 当地资料库和检索入口

- 亚洲及香港、台湾地区可从 [香港警务处 ADCC](https://www.adcc.gov.hk/zh-cn/alerts.html)、[台湾地区 165 全民防骗网](https://165.npa.gov.tw/)、[日本警察厅 SOS47](https://www.npa.go.jp/bureau/safetylife/sos47/case/)、[韩国联合应对门户](https://www.counterscam112.go.kr/campaign/index.html)、[新加坡警方](https://www.police.gov.sg/advisories/scams)和[印尼 IASC](https://iasc.ojk.go.id/)查。
- 美洲、大洋洲可用 [美国 FTC 主题库](https://consumer.ftc.gov/scams)、[加拿大 CAFC 字母索引](https://antifraudcentre.ca/scams-fraudes/azindex-eng.htm)、[巴西央行反诈](https://www.bcb.gov.br/golpes)、[澳大利亚 Scamwatch](https://www.scamwatch.gov.au/types-of-scams)和[新西兰警方诈骗、网络犯罪报案指引](https://www.police.govt.nz/use-105/fraud-scam-cyber)。
- 英国按地区核入口。英格兰、威尔士和北爱尔兰查 [Report Fraud](https://www.reportfraud.police.uk/faqs)，苏格兰查 [Police Scotland](https://www.scotland.police.uk/what-s-happening/campaigns/2020/take-five/personal/courier-fraud/)。欧盟各国的报案与消费者程序以当地当日规定为准。
- 中东和非洲可从 [阿联酋政府经济犯罪报告入口](https://u.ae/en/information-and-services/business/important-digital-services/reporting-economic-crimes)、[迪拜金融监管局预警](https://www.dfsa.ae/Your-Resources/DFSA-Alerts/Alerts)、[尼日利亚 EFCC 银行与网络账号反诈](https://www.efcc.gov.ng/ScamSafety/banking-and-online-account-scams)和当地警方查。

遇到表外地区或新名称，按[公开来源与查新方法](update.md)查当事人所在地的官方资料，同时查支付、通讯或旅行服务的原供应方。优先用要求的动作找中文大类，再看需不需要新增一条。涉及金额、期限、热线与损失追回能力时，应根据当日官方说明核实。
