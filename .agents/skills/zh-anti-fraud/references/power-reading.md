# 设局、官场与人心选读

想看完整故事，先读《二刻拍案惊奇》卷二十。想看日常交往里一个人如何占另一个人的便宜，先读《儒林外史》第六回。想知道一群各有打算的人怎样把传闻推成大案，可选孔飞力《叫魂》。以下读物均在[原有七种书目](books.md)之外。

## 五种小说里的局

| 作者、作品与篇章 | 读时值得跟住的线索 |
|---|---|
| 凌濛初《二刻拍案惊奇》卷二十 | 商家接到借用器物的府牒，特意派人去问，却恰好问到设局者本人。读到这里可以停一下：这次“问过了”究竟增加了什么证据？后文才向读者揭晓真相。[卷二十原文](https://zh.wikisource.org/zh-hans/二刻拍案驚奇/20) |
| 吴敬梓《儒林外史》第六回 | 掌舵的吃了船板上剩下的云片糕。等水手讨喜钱，严贡生才把糕说成贵药，众人只得替掌舵的求情。留意船家什么时候从要钱的一方变成需要自辩的一方。[第六回原文](https://www.shidianguji.com/book/CADAL02111881/chapter/1lcuhtrfirxft) |
| 李宝嘉（李伯元）《官场现形记》第二十五回 | 买古董、求引见、谋实缺都在这一回。顺着礼物和钱的去向读，分别记下中间人明确答应的事、求官者自己以为能得到的事。“实缺”指实际的职位。[第二十五回原文](https://zh.wikisource.org/zh-hant/官場現形記/25) |
| 吴趼人《二十年目睹之怪现状》第五、六回 | 从第五回的珠宝店案读到第六回的补叙。先只看珠宝商交付财物时已知的情况，等读到下一回，再补上当时看不到的那一段。[回目与原文入口](https://zh.wikisource.org/zh-hans/二十年目睹之怪現狀) |
| 凌濛初《初刻拍案惊奇》卷十六 | 张溜儿以媒人身份替陆蕙娘表态。读者可从女方角度重读相遇一节：她本人表达过什么，哪些话全由媒人代说？[卷十六原文](https://zh.wikisource.org/zh-hans/初刻拍案驚奇/卷十六) |

## 官场、权力与信息

| 书目 | 阅读入口 |
|---|---|
| 吴思《潜规则：中国历史中的真实游戏》 | 历史随笔。可从《身怀利器》《老百姓是个冤大头》入手，把纸面规则、谁有执行裁量、谁承担拖延成本分别写出来。作者对旧时官场的解释可与具体史料互读。[复旦大学出版社修订版书目及目录](https://libm.nwupl.edu.cn/bookInfo_0100058730.html) |
| 孔飞力《叫魂：1768年中国妖术大恐慌》 | 历史研究。先读第一章的“德清县的石匠们”，再读第八章的“民间的诬告”。同一传闻从邻里传到县衙、再进入奏报，陈述者各有压力。可逐处追问，新报告到底增加了哪个目击者。[三联书店版书目及章节](https://libm.nwupl.edu.cn/bookInfo_01h0033683.html) |
| 司马迁《史记·陈丞相世家》 | 史传。读楚使返回后项羽疑范增的段落：使者亲历的是接待时的变化，项羽接着对范增作出判断。把两件事分开读，便能看清中间少了哪一步证明。[篇章原文](https://ctext.org/shiji/chen-cheng-xiang-shi-jia/zhs) |
| 《荀子·臣道》 | 思想典籍。读开篇关于顺命、逆命与利君、害君的讨论。只观察一个人是否附和上司，容易漏掉其意见究竟保护或损害了谁。[篇章原文](https://ctext.org/xunzi/chen-dao/zh) |

## 人情、说服与误判

| 书目 | 阅读入口 |
|---|---|
| 费孝通《乡土中国》 | 社会学。读《差序格局》，理解亲疏远近怎样改变人们对义务的理解。拿“熟人介绍”来比较：介绍人的信用能说明他愿意作介绍，但要查那个人的资格，仍需另一项凭据。[高等教育出版社目录](https://xuanshu.hep.com.cn/front/book/findBookDetails?bookId=666731b674ce561611bda00e) |
| 罗伯特·西奥迪尼《影响力》 | 社会心理学通俗读物。选读英文扩充版讨论群体认同（Social Proof）与权威（Authority）的部分。比如群里十个人赞同一项投资，哪些人有独立交易记录，哪些只是转发同一张盈利截图？[作者书页](https://cialdini.com/books/influence) |
| 欧文·戈夫曼《日常生活中的自我呈现》 | 社会学。读“剧班”（Teams）相关章节，看同事如何协作维持一次对外接待的印象。礼仪分工也会产生整齐一致的说法；若要进一步认定有人说谎，应指出哪句可核的陈述有误。[英文版出版社书页](https://www.penguinrandomhouse.com/books/61106/the-presentation-of-self-in-everyday-life-by-erving-goffman/9780385094023/) |
| 玛丽亚·康妮科娃《我们为什么会受骗》 | 骗局案例与心理学通俗读物，孙鹏译，上海文化出版社。适合关心“已经发现不对劲，为什么还愿意相信”的读者。选一个案例，记下当事人第一次有理由改主意的时点。[广州图书馆书目](https://opac.gzlib.gov.cn/opac/book/3004367350?globalSearchWay=author) |
| 《吕氏春秋·去尤》 | 先秦寓言。一个人丢了斧头，看邻人之子的举止处处可疑。找到斧头后，再看同一个人便觉得寻常。适合与设局故事对读，问有什么新的事实会使自己改变判断。[篇章原文](https://www.shidianguji.com/zh/book/SBCK088/chapter/1j7136uau642x_93) |
