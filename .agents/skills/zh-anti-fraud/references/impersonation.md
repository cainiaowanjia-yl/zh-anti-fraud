# 冒充公检法、政府机关和使领馆

先读用户原话。“我是某公安局的”只是身份主张。“为了证明清白，把余额转入监管账户”已经足够让用户立刻停手。即使来电显示与机关公开电话一致，主动拨出一个从独立官方渠道查到的号码仍然有意义。[北京警方专题提示](https://gaj.beijing.gov.cn/xxfb/jwbd/202601/t20260115_4433143.html)

| 用户此刻面对的要求 | 优先回应 |
|---|---|
| 报警协查、银行卡涉案、护照异常，只通知联系某机关 | 问是否有转账、保密、安装软件等后续要求。记下单位和事项，结束通话，自行从政府或法院官网查总机或到窗口核对。真实事项也应及时核实。 |
| 对方发“通缉令”、证件视频，或在一通电话中层层转接 | 同一个来电、群聊及其引荐的人属于同一信息来源。截图、公章外观、制服或视频不能完成身份鉴定。独立询问该机关有无此事项、应如何正式办理。 |
| 要求将资金转入“安全账户”，以取现、寄黄金、交手机等方式自证清白 | 明确指出该项要求具有冒充公检法诈骗特征。停止汇款或交付，结束通话。人在中国大陆可自行拨打110；已交付时说明时间、方式及交易或运单编号。 |
| 要求打开会议软件、共享屏幕查银行余额或输入验证码 | 立即结束共享和通话。若已允许远控或设备无法操作，断开该设备网络，换可信设备联系银行。再按[止损指引](response.md)核对账户与授权。 |
| 要求住酒店、持续开视频、对家人保密或自行前往交接地点 | 恢复与可信任亲友联系，到有人值守的安全处。有人在场威胁时优先保护人身安全，用安全方式联系当地警方，避免当面对质。 |
| 家属收到“孩子被绑架”的电话、影音或赎金要求 | 按可能存在真实人身风险处理，尽快联系孩子所在地警方，使用原先保存的号码、学校或可信同住人同时核实平安。把最后已知地点和联系时间交给警方。不要仅凭一段视频断定已经绑架，也不要等到证实“虚拟绑架”才求助。 |

钱款可以留在本人账户内，风险也可能来自设备权限或银行卡授权。对方能说出真实姓名、护照号，甚至要求“先查来电号码”，都不能解释为什么要向陌生人交钱。面对境外来电，在驻外使领馆官网自行查询领保联系方式。个人所在地和家属所在地可能不同，说明各自联系哪个机关。[驻阿德莱德总领馆安全提醒](https://www.mfa.gov.cn/wjbzwfwpt/kzx/tzgg/202308/t20230828_11133442.html) · [香港警务处跨境购金警示](https://www.adcc.gov.hk/zh-hk/alerts-detail/alerts-2046139081996820481.html)

跨境时区分三个用途：当事人所在地警方处理当地紧急人身风险、受理当地报案；中国驻当地使领馆可提供领事协助；要核实对方所称的国内案件，可自行查找所称办案机关的公开渠道。案件或资金涉及多地时，向受理方说明涉及地区。不必等境内机关回电才在当地求助。

**可直接说给当事人的一句话**  
“先把共享关掉，钱留在自己的账户里。你可以用另一部手机自己拨号核实。对方有没有要求你转账，或者已经有人来取东西？” 如用户已说明情况，直接进入相应分支。
