# 核验清单与警示

用户问“怎么判断”“这是吹牛还是坑人”“给我个警示”时，先锁定他下一步要不要出门、付款、签字、交资料或担责任。答案要让他当下能做决定。先给最重要的两三项，复杂个案可以把每笔钱、每项权限和每次承诺逐项列出来。

## 每个疑点怎样变成可查的事

| 要核什么 | 独立从哪查 | 查到什么才进入下一步 |
|---|---|---|
| **机会确实存在，进展到哪一步** | 从正式招聘入口、原合同、项目业主或主管方，自行找到公开联络方式。询问项目全称、所在地点、负责单位和目前进展 | 能确认现在是介绍、沟通、具备采购条件、正在招采或可签约中的哪一步。项目真存在，只验证了项目本身 |
| **谁能承诺这件事** | 用已知通讯录、公开总机或原办事入口直接向有权的人确认。把介绍人原话与机构答复对照 | 确认此人可以做的那一步。例如能约见、能组织谈判、能代表业主签署，各自需要确认。职位、亲友、合照和见面只证明各自那件事 |
| **钱为什么交、付给谁、按什么结果结算** | 核书面约定、收费依据、授权收款方和户名。收款资料变了，从原合同约定的联系方式验证 | 交付内容、收款方、金额和退款或结算条件一致。意外出现个人收款、临时改款项用途、先付后补手续时，先暂停该笔动作，查真实授权 |
| **出了事谁担，如何撤回** | 核前后原话、合同和实际交付。口头说“我把钱还给你”，再确认指哪笔、金额、方式、时间和有无新增条件 | 能按原记录对账。款项实际到账后按对应款项记。财物返还另列，保留未结部分。等退款与开启新项目是两个决定 |
| **谁在催你，凭什么不能核** | 区分直接索求和传话，保存可见的原文。由真实机构或项目方通过独立入口确认真正时限 | 正规流程还有时限时可及时提交，未知付款照样暂停。拿抓人、封号或名额取消逼迫私下付钱、交证件或赴约时，先把涉险动作停住 |

对方发来盖章截图、项目编号或多人一致转发时，追问**这些内容是从哪里来**。同一个人给的两个号码、同一群转的一张图都需要独立确认。保密项目可用正式保密流程，让有权方确认它能公开说明的状态和这次接触的授权。用户可以在没有充分材料时决定承担多小的试探成本。

## 怎么给结论

- **可以继续某一步。** 独立来源确认了此人有权做这一步和相关条件。结论只覆盖已核事项。例如正式报名有效，照常报名。是否能中标、需不需要付费分别看。
- **信息不足，先暂停这一步。** 只有中间人口头保证，或关键范围说不清。说明缺哪一项，先改成线上了解、从原入口核对或按原安排提交。
- **已查出矛盾或正在被施压。** 有权方否认授权、收款和已核账户对不上，或有人拿执法后果逼私下配合。先保护钱、签字权、隐私和安全。对方的具体行为已有风险证据，动机、案件性质和其他人是否参与仍需证据。发生损失时走[止损与证据](response.md)。

## 把警示写成使用者记得住的一句话

用**他现在遇到的承诺、欠缺的凭据、该停的动作**写一句。比如“有人说包办，又让你先交钱。请先从业务决定者处核项目、从收款授权方处核这笔款。要素还对不上，就停在付款前。”有真实截止时间时，告诉使用者哪个环节可通过官方渠道同时保住。一个判断分成两件事时，逐件给结论。

**虚构练习。** 园区官网确有招募公告。熟人却要你今晚前转个人账户交锁位费，并承诺落选全退。你问凭证后，他改称要等项目验收再看。这里公告支持项目存在，收费授权还需核验，退款条款也发生了变化。暂停私人付款，从园区公告的公开入口核费用和实际报名截止时间。若确认官方报名有效，按原入口申请。已转过的款保留流水和两版约定，联系付款机构了解可采取的措施。可以回“我会直接向园区核实收费和退款条件。官方报名我按公告走，这笔钱先暂停。”
