# 真带人的大哥、夸口者与设局者怎么辨

“大哥”可以是前辈、领导、带教、合伙人或中间人。按这一件事判断他的行为。一个人可以在上一次帮过忙，在这一次夸大了权限，也可能只擅长某一行。先问他**实际做了什么、还能做什么、现在要求你承担什么**。

| 哪种解释较符合现有证据 | 可以核实的表现 | 此刻的决定 |
|---|---|---|
| **真带人或提供真实有限的帮助** | 花时间讲方法、给具体反馈、安排可以独立确认的引荐。讲清自己能保证哪一步、由谁拍板、自己从中是否获益。用户可以直接联系经办人，也可以停下来 | 先接可确认的一步，自己保留材料、选择和决定权。把目标、交付与时间说明白 |
| **人有好意，能力、资源或权限有限** | 确实尝试过，引荐、排期或交付能独立确认。出现差错后会承认边界、纠正错误、请有能力的人接手，或接受取消 | 降低依赖，改找能拍板或有经验的人。可以感谢那部分帮助，关键事项另核 |
| **夸口，或能力还未经证实** | 把认识说成能办，把可递交说成包成功，把团队成绩全说成自己做的。对责任、成果、条件和期限反复给不出明确答复 | 暂按能验证的工作范围合作。让他讲一件同类项目中自己具体负责的部分，或先做一项小而可撤回的工作 |
| **有证据指向诱骗、隐瞒或利用** | 授权被有权机构否认仍冒称获批，使用已查证的假文件反复索款，隐瞒自己收钱或抽成，或一边说在帮你，一边阻拦直接核验、催你个人担保或把责任留给你 | 先停下新增付款、签名或授权，保留原记录，直接核实。已经损失或面临人身风险时优先用[止损指引](response.md) |

一次迟回或办砸既可能是疏忽，也可能是能力、权限、资源、外部条件或责任心出了问题。查证时找能区分几种解释的事实：

1. **把承诺拆开。** “我能递简历”“我能让你见负责人”“我能决定录用”是三个不同权限。问哪一步已做，最后由谁决定。做生意时把客户愿不愿谈、真实订单、收款权限逐项核对。公务上核岗位权限与书面程序。
2. **看能力和交付。** 能说出做法与限制、能交出可验成果，比合影、头衔和同桌吃饭更有分量。能帮做一次小事，证明的是那一件。合理的小合作可以用真实任务，双方事先同意，范围、时间和责任写清楚。遇到高风险要求可直接停。
3. **看利益和边界。** 问对方怎么收费、由谁收、何时兑现、自己得什么。收益公开且双方能核对的介绍、培训或合作有可能正常。只因为对方抽成，尚不足以下结论。明明查得到正式负责人，却坚持只能经他转述，或把个人风险藏在合作条款里，可暂停。
4. **看给出新证据后的反应。** 例如正式联系人确认仅代递申请。对方更正了“保证拿到”的说法，支持过度承诺或误解。若他知道权限已被否认却继续虚称获批，并借此要求付钱，才有更具体的故意误导迹象。压力升温的依据见[流程与风向](situation-trend.md)。

## 回答时落到这一件事

可写“事情目前更像夸口。能确认的帮助是递简历，暂未核实他有权保证面试。你现在可以恢复投递”。另列一条会改变判断的新信息即可。证据复杂时可按人列“能确认的帮助｜超出权限的许诺｜当前索取和获益｜待核”。用户问谁在接力时，仍按[故事拆解](story-analysis.md)写可见动作。真实的介绍、在场或转述都各有范围。

**虚构示例。** 月初，甲确实给我介绍过小订单，我很感激。昨晚，甲说采购方已批准大单，乙转同一张截图并催“别不给面子”，让我今晚给丙的个人账户垫保证金。我怕错过，随后用原合同电话查到采购方未授权这笔钱，既着急又生气。

- **阶段和风向。** 从过去真实的帮助转到新索款。限当晚付到个人账户，且采购方明确表示未授权，风险随之上升。感激能解释我为什么一开始愿意听下去，采购方答复才改变了此次付款依据。
- **谁在接力。** 甲宣称获批，乙复述并催付，丙是指定收款人。甲是否明知无授权、乙是否只转述、丙是否实际控制该户，仍需各自的证据。
- **立即应对。** 这笔款先停。可回“前次帮忙我记得。这次采购方没有确认保证金，我先不付。请让采购从原渠道给我正式说明。”可用《杜骗新书》的“假马脱缎”作对照，讨论谁又借用了谁的信用。[典故原文](https://zh.wikisource.org/wiki/杜騙新書/01#假馬脫緞)
