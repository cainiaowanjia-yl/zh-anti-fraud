# 识人和识局的典故

普通故事有直接对应时选一则。复杂深拆选几则各有用途的典故，放在对应的做局点旁。每则用一两句话讲原书写了哪一步、眼前哪一步相似、应当核实什么。写明篇章、文类及原文出处。典故帮助看清机制，现实行为仍按记录核验。[做局深拆](deep-analysis.md)

| 典故及出处 | 对照现实故事时看哪里 |
|---|---|
| **萧何追韩信。** 《史记·淮阴侯列传》写萧何亲自追回韩信，向汉王举荐并推动正式任命。同一传记后段也记载，吕后后来与萧何谋划召韩信入宫。[《史记·淮阴侯列传》原文](https://www.shidianguji.com/zh/book/HY3994/chapter/1ksz5gbhz9ctf) | 真举荐有具体引荐、正式机会和决定者。过去的提携有过真实作用，今天的要求仍须看今天的条件 |
| **孙权劝学。** 《资治通鉴》卷六十六写孙权让吕蒙从涉猎旧事入手，吕蒙学习后与鲁肃议论，鲁肃重新评价他。[《资治通鉴》卷六十六](https://zh.wikisource.org/zh/資治通鑑/卷066) | 真带教可从具体方法、练习、反馈和后辈是否更能独立做事来观察 |
| **庞统任耒阳令。** 《资治通鉴》卷六十六写庞统任县令时未能治理好，免官后经鲁肃和诸葛亮举荐，受刘备另用。[《资治通鉴》卷六十六](https://zh.wikisource.org/zh/資治通鑑/卷066) | 岗位上的一次失败可能表明不适合这项任务。进一步查任务特点、授权、资源及同类结果 |
| **赵括代廉颇。** 《史记·廉颇蔺相如列传》记有外部误导，也记蔺相如对赵括实战应变的质疑。[《史记·廉颇蔺相如列传》](https://www.shidianguji.com/book/CADAL01034053/chapter/1l47wkkl7chsr) | 一件事里，外部有人操纵消息和经办者能力不匹配可以并存，分别找证据。失败结果本身难以确定参与者的意图 |
| **滥竽充数。** 《韩非子·内储说上七术》以南郭处士在合奏中混过去、改为单独听奏便离开的故事说明核验个别贡献的意义。[原文](https://zh.wikisource.org/zh-hans/韓非子/內儲說上七術) | “我们做过大项目”值得追问他具体完成了什么，他夸口的那项能力能否在同类任务中验证 |
| **画地作饼。** 《三国志·魏书·卢毓传》记魏明帝谈选人时，以地上画的饼无法食用比喻名声。卢毓主张用事功检验。[《三国志》卷二十二原文](https://www.shidianguji.com/zh/book/CADAL01027428/chapter/1ljtrzb822cyi) | 出发或付款之前，先验实际权限和已经交出的东西。原典讲用人，拿来对照生意时，可以问“名头、项目材料和已经到账的钱分别有什么凭据” |
| **先寄银而后拐逃。** 《杜骗新书》写纪胜先把自己的银子寄存在苏广箱中，取得信任，后来试图带走箱子。按语称“欲取姑与”，故事正文也写到相处日久后见利生奸。[原文](https://zh.wikisource.org/wiki/杜騙新書/01#先寄銀而後拐逃) | 前面确有帮助或交付，之后才提出风险更大的要求。逐件核对回报义务，以及是事前计划还是后来见到机会 |
| **假马脱缎。** 张应俞《杜骗新书》写取货者借马及马贩在场使缎铺放松警惕，后续才查清人物关系。[《杜骗新书·假马脱缎》](https://zh.wikisource.org/wiki/杜騙新書/01#假馬脫緞) | 先确认在场人、引荐人和承诺担责者各自做过什么，再看能否证明有人知情配合 |
| **贾廉访赝行府牒。** 《二刻拍案惊奇》卷二十写贾廉访利用亲家关系和真账目，借官府名义取走财物。商家先向亲家打听，后来才由发文机关核出假府牒。[卷二十原文](https://zh.wikisource.org/zh-hans/二刻拍案驚奇/20) | 说得出真实细节、有真实职务或认识真的官员，可以增加可信感。要核的是这项具体指令由谁发、有什么权限 |
| **众端参观。** 《韩非子·内储说上七术》用多人附和季孙的故事讨论判断是否受同一来源左右。[篇章原文](https://zh.wikisource.org/zh-hans/韓非子/內儲說上七術) | 从各方各自掌握的一手记录核对关键事实。多个群友重复同一个人的说法，仍然只有一个源头 |
| **疑邻盗斧。** 《吕氏春秋·去尤》写丢斧者起疑后，看邻人之子的举止都像偷斧。找回斧以后，同样的举止又显得平常。此故事也见《列子·说符》。[《吕氏春秋·去尤》](https://www.shidianguji.com/zh/book/SBCK088/chapter/1j7136uau642x_93) · [《列子·说符》](https://www.shidianguji.com/zh/mid-page/7596072872193228809) | 把当时感觉与后来能独立查证的东西分别放回时间线上。发现能够推翻旧解释的新事实后，更新判断 |
