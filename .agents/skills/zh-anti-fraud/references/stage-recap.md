# 按时间复盘当时怎么想、怎么决定

让用户照自己记得的经过说。若需要提示，“当时发生了什么，你那时最在意什么，接下来做了什么？”已经够用。用户愿意说多少就用多少。时间不清楚可以用“第一次见面”“临签前”“独立核验后”。

把“我那时知道的”“我那时以为的”“我后来才查到的”放回各自时点。心理状态优先用用户的词，缺失就写“当时感受未提及”。有犹豫、期待或感激，可以问这些感受和当时哪条信息有关。判断其他人的心理只引用其明确表达，并保留他所说的与他真实所想之间的距离。

| 故事走到哪一步 | 听当事人怎么讲 | 对判断有什么用 |
|---|---|---|
| 第一次接触 | 最初想解决什么？谁出现，说能帮什么？当时有什么想法？ | 找到用户当初的需求与预期。接触和帮忙也可能只是日常往来 |
| 开始相信 | 是哪句承诺、哪次帮忙、谁的引荐让你改变判断？ | 找到最初有效的信任依据，看看它能证明哪一件事 |
| 开始答应或承担 | 你真正答应了什么？什么时候决定停投、给资料、署名、借钱或先垫款？ | 把决定和代价对起来。可能有人在这一步把口头意向当作承诺 |
| 第一次觉得有变化 | 哪句话或哪项条件和前面不同？你那时怎么解释？事情还能暂停吗？ | 找到风险的转折点，记录对方改的是时间、权限、责任、收款人或核验渠道中的哪一项 |
| 核实后重新判断 | 第一次从独立渠道听到或看到什么？如今的感受和当时有什么变化？ | 更新对相关人的判断，写明哪项解释获得支持，哪项还等证据 |

这些时点可跳过、重叠，也可能一句话就跨几步。用户当时很害怕，说明他面临的压力，具体风险仍要看对方的要求与记录。用户现在很生气，也可能是因为误了承诺或浪费时间。复盘以理解当时为何会做那个决定为目的，避免用事后的信息要求当事人当初就该看出来。

**虚构示例。** 周一，老同事说“这周保证能进面试”，我很兴奋，暂停了别的投递。周四没回音，我觉得被耍了。后来招聘人确认收过简历，并说从没许诺面试。老同事也承认说过头，愿意给我改简历。

| 时间 | 当时的心态和动作 | 现在能核实什么 |
|---|---|---|
| 周一 | 因为信任老同事和“保证面试”而兴奋，暂停投递 | 这一步损失的是求职选择。此时只有老同事的保证 |
| 周四 | 没收到消息，开始怀疑 | 延误支持进度未达预期，仍可能是权限有限、流程延迟或夸口 |
| 招聘方回覆后 | 可以重新评估早先的承诺 | 转递简历属实。“保证面试”超出已核实的权限。后续适合继续投递，直接问招聘方进度，把介绍人与结果决定者分开 |

若过往感受与眼下紧急风险同时出现，先处理付款、权限、签字或人身安全。用户想理解整段关系时，再用[识人辨析](mentor-assessment.md)并列几种解释。贴切时可引用“疑邻盗斧”，说明新证据如何改变对同一行为的理解。[《吕氏春秋·去尤》](https://www.shidianguji.com/zh/book/SBCK088/chapter/1j7136uau642x_93)
