# 从传统识局读到现代反诈

想直接读一个局怎样发生，可从[《二刻拍案惊奇》与其他选读](power-reading.md)入手。想找法院、检察院等机构披露的实际事件，可查[涉及公权力的案例](authority-cases.md)。

读者说“腹黑学”时，先确认是泛指权术题材还是寻找特定作者。下面各书在读法上有差别。涉及当前人物和具体交易，回到当事人可以核实的事实。

| 书目 | 文体与阅读入口 |
|---|---|
| 张应俞《杜骗新书》 | 晚明骗局故事与作者评点。可先选一篇，分开写下当事人实际目睹的事情、他听信的说法、故事结尾才揭晓的事实。麦田新注校勘全本以《骗经》为题，ISBN 9786263108943；哥伦比亚大学出版社英文版为选译。[中文版本书目](https://isbn.ncl.edu.tw/NEW_ISBNNet/main_DisplayRecord_Popup.php?KeepThis=true&Pact=view&Pkey=1140501%2A0236&TB_iframe=true&height=480&width=780) · [英文选译简介](https://cup.columbia.edu/book/the-book-of-swindles/9780231178631/) |
| 连阔如《江湖丛谈》 | 民国江湖行当和市井见闻。适合查行业用语、卖艺与谋生环境；谈某项行规时查回具体章节和时代。[中华书局试读](https://www.chunghwabook.com.hk/upload/files/2023/03_01/002c10c0cd6a8c1f07d7d41f11529ac8.pdf) |
| 李宗吾《厚黑学》 | 民国讽刺文字。选正文读作者怎样评论历史人物。版本带有“原典”“编著”“译著”等署名时，区分李宗吾原文与后人发挥。[广西大学图书馆版本与目录](https://opac.gxu.edu.cn/bookInfo_01h0043712.html) |
| 高阳《千门八将》第一部《八将聚首》 | 网络作家高阳所著当代长篇小说。江苏凤凰文艺出版社2016年版，ISBN 9787539994611。可讨论小说人物、悬念与江湖想象。若问“八将”是否真实存在、各称谓有无固定史源，需另找有版本与年代的文献，标明不同说法。[丽水学院图书馆书目](https://huiwen.lsu.edu.cn/space/searchDetailLocal/mdb554d8c7dee22dea15af2b01eeb330c) |
| 《韩非子·内储说上》 | 先秦政治思想。可从“众端参观”读起。对应到现代核验，一个问题是：不同人的说法分别源自独立观察，还是都来自同一封通知？[原文](https://ctext.org/hanfeizi/nei-chu-shuo-shang/zhs) |
| 冯梦龙辑《智囊》 | 明代故事汇编。建议读“察智”中的“得情”“诘奸”。适合讨论叙事中的疑点如何被发现，以及结局已知会怎样影响读者的判断。[《察智部总序》与卷九](https://zh.wikisource.org/zh-hans/%E6%99%BA%E5%9B%8A/09) |
| 《战国策·齐策一》 | 读《邹忌修八尺有余》（常题作《邹忌讽齐王纳谏》）。同一句肯定能出于亲近、顾虑或有所求，理解各自处境也能解释一致表态。[《战国策》卷八目录与底本](https://ctext.org/library.pl?if=gb&remap=gb&res=85288) |

如果读者关心当代社会中的相似现象，可以选一篇古代故事和一个有原始通报的现代案例比较。在两栏分别列出时代、来源、作者能知道什么、读者能核实什么。把文学中的叙述视角留在作品里。
