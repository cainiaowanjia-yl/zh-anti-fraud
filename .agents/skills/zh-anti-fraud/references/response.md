# 按实际暴露情况止损

优先处理仍在进行的交易、设备控制和人身危险。可由可信亲友同时协助联系银行与警方。没有拿齐证据也能先求助。

| 已发生的事 | 当下动作 | 留给后续核对 |
|---|---|---|
| 只接到通知，还没操作 | 暂停当前对话，从原订单、既有通讯录、卡背号码或机构官网主动联系 | 时间、对方原话、所要求的动作 |
| 只点了链接 | 关闭页面，确认有无输入资料、批准登录、下载安装、添加支付授权或异常扣款；按实际动作分流 | 短信原件、页面显示的域名；不为取证重开链接 |
| 输过密码或交过验证码 | 从可信设备进入真实平台，修改相关及复用密码、退出陌生会话，检查恢复方式和支付授权；涉及金融账户立即联系银行 | 记录泄露的是哪类凭据、发生时间和账户通知；无需告诉助手具体值 |
| 开过屏幕共享或远控 | 立刻断开共享；对方仍能操作时断网，用另一台设备联系银行/支付平台查账、限制风险交易。随后撤销远控权限、处理陌生应用、检查账户。避免在受控设备上改密 | 软件名称和授权范围，是否在共享时打开银行、收到验证码或做过人脸验证 |
| 银行转账、银行卡或支付平台扣款 | 立即联系付款机构官方客服，说明涉嫌诈骗，请其登记并评估止付、撤回、争议或挂失途径，同时向所在地警方报案 | 金额、准确时间、付款渠道、收款方、交易流水、机构受理编号 |
| 交付现金、黄金或寄件途中 | 未交付则停止交付；已寄出立即用承运商官方渠道申请拦截并报警。上门人员仍在附近时避免追赶或自行取回 | 运单、下单渠道、交接地点与时间、物品凭据 |
| 已给购物卡兑换码，或转出数字资产 | 联系发卡方或使用的平台官方支持，请其登记、核查余额或交易状态。保存卡片或交易哈希。到账可否拦截以机构答复为准 | 购卡凭证、金额、时间和交易编号。卡密、助记词、私钥不要发给助手或“追款人” |
| 已交身份证件或做人脸验证 | 问清涉及哪个机构及用途，用其真实渠道查有无新办业务、登录或借贷；发现冒用即提出异议并留存受理凭据 | 证件种类、时间、渠道、异常记录。完整证件只经核实的机构渠道提交 |
| 遭私密影像勒索 | 停止付款和继续发送影像，保存威胁文字、账号及时间，向平台与所在地警方求助。涉及未成年人可请可信成年人陪同。无需转发影像给助手 | 已发布内容的标识、威胁记录、付款记录 |
| 对方称可“追回被骗款”，先付保证金 | 中断新付款，沿原银行、支付平台或警方的已核实渠道追踪原案进展 | 区分原交易和二次索款，分别记录账号和时间 |

中国大陆紧急报警用 **110**。**96110** 用于反诈预警劝阻等服务，已发生损失直接报警并通知金融机构。大陆以外先确认所在地，按当地警方官方页面提供的渠道办理。对退款、冻结和追回只说明可申请的动作及已获回复。[公安机关止损说明](https://www.fuxin.gov.cn/content/2026/1101089.html) · [国家反诈中心手册，第17页](https://by.china-embassy.gov.cn/lsfw/lingshibaohuyuxiezhu1/202512/P020251229757139157854.pdf) · [北京警方远控处置说明](https://gaj.beijing.gov.cn/xxfb/jwbd/202601/t20260115_4433143.html)

银行卡、购物卡、数字资产等支付方式各有不同的处置渠道。美国 FTC 的分类可作机制参考，美国的报案入口和消费者权利只按当地现行规定引用。[FTC 分支付方式处置指南](https://consumer.ftc.gov/articles/what-do-if-you-were-scammed) · [私密影像勒索及收费援助风险](https://consumer.ftc.gov/consumer-alerts/2026/10/how-avoid-deceptive-sextortion-assistance-services-and-find-real-help)

## 可代填的报案摘要

按用户已经给出的事实填空，缺项写“待补”。同一笔款同时出现在聊天截图和银行流水时只计一次；账户页面显示的收益、已实际支付的钱和实际到账的退款分开列。保留原件，分享给助手的副本可遮盖姓名、账号与定位。截图尽量保留日期、对话上下文、平台名。

> 我在〔所在地〕于〔日期、时间及时区〕通过〔渠道〕接到自称〔身份〕者的联系。对方声称〔原话摘要〕，要求〔具体动作〕。我实际做了〔动作〕。付款〔笔数、币种、金额与交易时间〕，实际收到退款〔金额或待核〕。最后一次联系在〔时间〕。我已通过〔自行找到的官方渠道〕联系〔机构〕，结果为〔已登记／已答复／待回电〕。现有材料包括〔聊天、来电、回执、运单等〕。

需要向银行说明时，可以说：“我怀疑这笔交易涉及诈骗，付款时间和金额是……。请帮我核对交易状态，登记风险并告知目前可采取的止付或申诉方式。” [公安机关证据清单](https://www.bjfsh.gov.cn/ztzx/2023/fsqfzzt/fzzs/202307/t20230706_40063990.shtml)
