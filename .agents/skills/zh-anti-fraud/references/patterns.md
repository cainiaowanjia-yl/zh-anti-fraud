# 诈骗类型与变种索引

海外常用叫法、当地支付与旅行变种、跨境求助入口查[海外与跨境骗术索引](global-scams.md)。可按对方要求的动作对照两份索引。

资料检索至 2026-11-21。下表按用户看到的情境检索。同一次事件允许多个标签，例如“婚恋交友 → 虚假投资 → 提现前收费”。网络流行的新名字可以归入同一类。先确认实际发生了哪一种索款或授权，再判断风险。

## 大陆十类高发电诈

十个类别来自公安部 2026 年 6 月新闻发布会。以下核验办法为面向当事人的整理，类别先后顺序不表示风险排名。[公安部发布会通报](https://www.shanwei.gov.cn/swsgaj/gkmlpt/content/1/1254/post_1254298.html) · [宣传手册案例与目录，第5至14页](https://by.china-embassy.gov.cn/lsfw/lingshibaohuyuxiezhu1/202512/P020251229757139157854.pdf)

| 类别 | 从什么情境认出来 | 哪一步可以独立查证 |
|---|---|---|
| 刷单返利 | 点赞、关注、试单有小额到账，下一单却需垫资，还可能要求补齐“联单” | 核对自己实际支出和到账；停止垫资。一次返佣只能证明那笔钱到过账 |
| 虚假购物或服务 | 二手交易、低价代购、特价商品、代办服务转到私聊，交了定金又追加费用 | 手动打开原平台查有无真实订单、平台担保和退款入口 |
| 虚假网络投资理财 | 投资群荐股、虚拟币项目、内部账户显示收益，提现前另收税费或保证金 | 从监管机构公开名录核主体，再通过该机构官方渠道核实产品、销售人员和收款账户 |
| 冒充电商物流客服 | 商品理赔、快递损坏、误开会员或“百万保障”，退款竟要共享屏幕、出验证码 | 从本人订单页或账户订阅设置查询；使用平台内原有客服入口 |
| 贷款、征信 | 放款之前先交费、刷流水；有人声称能收费消除逾期，或发“律师函”催登录 | 在原借贷机构核实际账单和征信异议渠道。避免扫描来函内的还款码。[江门警方实例](https://www.jiangmen.gov.cn/bmpd/jmsgaj/zwgk/sjfb/content/post_3588792.html) |
| 网络游戏虚假交易 | 收号、代充、送皮肤、解除防沉迷，却要交解冻金或让孩子拿家长手机验证 | 从游戏内客服查交易规则；孩子可中断聊天找可信成年人。[校园预警](https://wxb.xzdw.gov.cn/wlaq/yjtb/202610/t20261009_701072.html) |
| 网络婚恋交友 | 刚建立亲密关系便引导投资、借急用钱或进入指定平台；催促保密 | 分开核实人物与资金用途。即便对方真实存在，项目仍需独立核验 |
| 冒充公检法 | “涉案资金核查”“安全监管账户”、屏幕共享查资金、取现交金自证 | 立即停下该项操作，用另一条渠道联系当地警方。[专项核验](impersonation.md) |
| 冒充领导、熟人 | 换号借款、冒充老板安排紧急汇款；头像声音熟悉也可能是冒用 | 用原有号码主动联系本人。企业另走既有审批流程 |
| 机票退改签 | 对方知道航班信息，以补偿、改签或延误险为由引导到另一个支付页面 | 手动查航司或原出票平台的航班和退改政策，分别核实变更与赔付 |

## 生活、组织与跨境场景

以下是额外检索入口，既含高发类别的变种，也有线下骗局、勒索及其他相关风险。来源所在地区仅说明案例出处。办事和报案渠道按用户所在地核验。

| 情境 | 决定性的核验问题或动作 | 公开资料 |
|---|---|---|
| 虚拟绑架、留学生失联索赎 | 从已保存号码、学校或同住人核实本人安全；家属同时向当事人所在地警方求助 | [外交部领保案例](https://www.mfa.gov.cn/wjbzwfwpt/kzx/tzgg/202308/t20230828_11133442.html) |
| 假换汇、代缴海外学费 | 用校方缴费系统确认款项确已入账，向持牌机构核交易。一张付款截图不能证明到账 | [驻多伦多总领馆](https://www.mfa.gov.cn/wjbzwfwpt/kzx/tzgg/202307/t20230706_11109227.html) · [驻墨尔本总领馆](https://cs.mfa.gov.cn/zytz/202607/t20260721_11988182.html) |
| 商务邮箱诈骗、供应商改收款账号 | 用合同档案里原有的号码向收款方回拨，重新核实变更；同一邮件线程中的回复不构成独立确认 | [美国 FBI IC3 商务邮件诈骗](https://www.ic3.gov/CrimeInfo/BEC) |
| 招聘转培训、入职先办贷款 | 核对招聘主体、签合同的公司、借款人分别是谁，再向用人单位官方招聘渠道确认岗位 | [人社部等五部门](https://www.mohrss.gov.cn/wap/xw/rsxw/202605/t20260515_576264.html) |
| 网课退费、清退群要求再买基金 | 回原培训机构核对合同、退款和到账方式；暂停新购产品 | [江苏省公安厅](https://gat.jiangsu.gov.cn/art/2025/2/13/art_89956_11491351.html) |
| 冒充老师收班费 | 用原通讯录联系班主任或校方，确认项目与收款人 | [武汉警方校园指南](https://3g.wuhan.gov.cn/hdjl/rdhy/202603/t20260306_2736536.shtml) |
| 追星福利、演唱会票务 | 通过主办方公布的票务入口核票；所谓内部票、粉丝群“解冻费”不能作凭据 | [网信部门警示](https://wxb.xzdw.gov.cn/wlaq/yjtb/202610/t20261009_701072.html) |
| 假房源、先付看房押金 | 核实房源、房东权属或代理授权，独立联系物业或中介；同照片不同联系人值得查证 | [美国 FTC 租房提示](https://consumer.ftc.gov/articles/rental-listing-scams) |
| 虚假中奖、彩票、领奖先缴税 | 自行找主办方核活动记录；收到“缴费换奖金”要求时停付 | [美国 FTC 中奖警示](https://consumer.ftc.gov/articles/fake-prize-sweepstakes-and-lottery-scams) |
| 假慈善募款 | 自己查公益组织及官方募款项目，通过核实的募款入口捐助 | [美国 FTC 消费者资料目录](https://consumer.ftc.gov/articles) |
| 假技术支持、设备弹窗报毒 | 关闭提示，从设备厂商原有支持渠道查询；拒绝来历不明的远控和付款要求 | [美国 FTC 诈骗主题资料](https://consumer.ftc.gov/articles) |
| 假水费、电子罚单或公共服务短信 | 从原账单或机构官网查欠费、罚单，不在短信入口提供卡资料 | [香港警方预警索引](https://www.adcc.gov.hk/zh-hk/alerts.html) |
| 养老床位预存、养老项目高息分红 | 确认机构资质、合同约定服务和退费条件，单独核查资金募集资格 | [最高法六类养老案例](https://www.court.gov.cn/zixun/xiangqing/369761.html) |
| 收藏品高价回购、以房养老投资 | 独立核定实际价值、抵押权及资金去向；暂缓签约过户 | [最高法案例三、四](https://www.court.gov.cn/zixun/xiangqing/369761.html) |
| 代办养老保险、假义诊卖特效药 | 向参保地公共服务渠道核政策，到正规医疗机构核诊疗需求 | [最高法案例五、六](https://www.court.gov.cn/zixun/xiangqing/369761.html) |
| 民族资产解冻、冒名扶贫发钱 | 在主管部门官网核实项目；“先缴会员费才可领国家补助”值得立刻停付 | [浙江检察机关典型案例](https://www.zjjcy.gov.cn/art/2022/9/20/art_26_195691.html) |
| 街头祈福消灾、交金饰保管 | 财物留在自己手中；离开现场，独立联系家属确认平安 | [香港警方祈福党案例](https://www.adcc.gov.hk/zh-cn/alerts-detail/alerts-1444920527176138754.html) |
| 裸聊、合成影像勒索、付费删图 | 对方索款即处置勒索，不需要用户证明影像真假。保留威胁记录，不传私密影像，联系平台和警方 | [美国 FTC 勒索援助风险](https://consumer.ftc.gov/consumer-alerts/2026/10/how-avoid-deceptive-sextortion-assistance-services-and-find-real-help) |
| 假追损、假维权、假反诈客服 | 向原受理机构核承办人。陌生人声称能追回损失却先收保证金时中止 | [美国 FTC 二次诈骗警示](https://consumer.ftc.gov/consumer-alerts/2026/08/have-you-lost-money-scam-watch-scammers-who-say-they-can-help) |
| 出借“两卡”、代收款或受托提货 | 暂停代收代转，保留指示记录。若钱已进账，请银行及警方指导处理，避免另转陌生账号“退款” | [公安部刑侦局新版手册说明](https://ch.china-embassy.gov.cn/zytz/202607/t20260701_11956016.htm) |

## 容易跨类出现的动作

- **指定付款介质。** 礼品卡兑换码、数字资产、黄金、现金和贵重商品都可能替代普通转账。先问“交了什么、是否已经送达”，再找对应机构。[公安部发布会](https://www.shanwei.gov.cn/swsgaj/gkmlpt/content/1/1254/post_1254298.html) · [购物卡实例](https://consumer.ftc.gov/consumer-alerts/2024/02/check-out-line-buying-gift-cards-read-avoid-scam)
- **换入口或交出权限。** 从快递小卡、积分短信、二维码进入陌生页面，或以 NFC 贴卡、共享屏幕为名核验。手动打开可信应用查业务；已操作的按[止损指引](response.md)处理。即使软件本身真实，给出指令的人的身份也要核实。[手册关键词第33至42页](https://by.china-embassy.gov.cn/lsfw/lingshibaohuyuxiezhu1/202512/P020251229757139157854.pdf) · [工信部2026年第三批通报](https://wap.miit.gov.cn/gyhxxhb/jgsj/wlaqglj/ffzldxwlzpy1/art/2026/art_e1595d07de4e4fa694d24d189042982b.html)
- **借人声、视频或多个账号制造信任。** 从早已保存的渠道联系本人，并核实款项的最终去向；多人转述同一消息，只能算一条信息链。不要凭肉眼推断某段影音一定由 AI 合成。[驻法使领馆风险提示](https://cs.mfa.gov.cn/zytz/202607/t20260721_11988598.html)
