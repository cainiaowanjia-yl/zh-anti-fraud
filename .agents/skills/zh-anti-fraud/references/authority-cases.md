# 涉及公权力的四起公开案例

“官员骗局”可能指官员受骗、有人假冒公职人员，或真实经办人利用职务造假。先说明人、职务、具体事项与实际行为各有什么证据。以下选取四起有具名发布机构的案例，材料核对至 2026-11-21。

| 情境与出处 | 资料披露的事实 | 对照现实情境时可以核实什么 |
|---|---|---|
| **公司内部人引荐假财政厅工作人员。** 河南南阳中院，2009-06-15，二审裁判报道 | 宋喜峰冒充省财政厅工作人员，由涉事公司销售员江献银引见，声称能引来政府贴息贷款，以活动经费为由向公司骗取34.3万元。两人均以诈骗罪获刑，二审维持原判。[南阳中院](https://nyzy.hncourt.gov.cn/public/detail.php?id=969) | 引荐人确在本公司任职，能证明的只是引荐人的身份。可独立找主管部门公开的申报指南，核对该项目、受理单位以及有没有这笔费用。 |
| **在派出所门口自称能摆平纠纷。** 江西赣州章贡区检察院，2025-07-31，报道一审结果 | 报道中的“小明”在派出所门口自称民警。后来多个账号以“同事”“领导”等身份与当事人联系，实际由同一人使用，共骗取4万余元。区法院一审以招摇撞骗罪判处有期徒刑二年。[章贡区检察院](https://www.ganzhouzg.jcy.gov.cn/yasf/202507/t20250731_7071792.shtml) | 办公地点可以是真的，见面者身份及经办权限仍要向窗口独立核实。几个相互介绍的账号可能只有一个消息源。 |
| **官员相信所谓高层关系。** 《永远吹冲锋号》第一集，2023-01-07，调查专题片 | 据节目披露，李全自称是领导身边的智囊，傅政华长期相信他，曾帮助其推动土地开发、协调纠纷及为其亲属安排工作。关于李全身份及二人交往细节，引述依据为节目调查与受访者陈述。[专题片全文](https://news.cctv.com/2023/01/07/ARTIuOfCImDSacJFhQFRZSQQ230107.shtml) | 把“说自己替人办成了事”和“能从决定作出者处独立确认其实际作用”分开。某人的职务后来果然有变动，本身无法证明自称有门路者起了作用。 |
| **真实财政经办人虚报补贴。** 黑龙江省纪委监委通报，2023年6月公开 | 何景超任鸡东县鸡东镇财政所专管员期间，虚增土地面积，套取耕地地力保护补贴82.36万元，用于个人消费。通报载明鸡东县法院于2023年3月判处其有期徒刑三年三个月。[纪检监察通报第2例](https://www.bxjw.gov.cn/news/YASJ/202362/236215382295398F14CF43FADJ9EDG.html) | 即便经办身份属实，申报事项仍可失真。这类核验应落到原始面积记录、申报表和拨款明细；个人只能向有权机构查询自己有权取得的记录。 |

用户说“有人能帮我办事”时，最有区分力的问题往往是：**哪家机构有权决定？这项收费或办理承诺，能否从该机构自行找到的窗口得到同样答复？** 若对方催促转款或保密，可先暂停交付。已产生支出时，按[止损与证据](response.md)整理记录。不因某人被冒名或出现在合影中就推定其参与。
