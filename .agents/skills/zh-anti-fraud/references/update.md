# 公开来源与查新方法

本包检索截至 **2026-11-21**。中国大陆资料见[类型索引](patterns.md)，亚洲、欧洲、美洲、大洋洲、非洲及跨境资料见[海外索引](global-scams.md)。公开通报有发布滞后，同一骗术也有多个名字。遇到“网上所有诈骗”，说明实际检索的地区、机构、资料类别、日期和未覆盖部分。用户只问一个案子时，只查与它有关的官方资料；进行中的紧急事项先处置。

## 查新与收录

1. 从用户描述提取“对方声称的身份／借口＋要求的动作＋地区”。例如查“网课清退 买基金 公安”，比只查“被骗”更容易找到同一机制。用简繁体及当地用语交叉检索，如“刷单／做任务”“安全账户／资金审查”“假冒官员／冒充公检法”。涉及海外时可另查当地支付工具、主管机关和原语别名。无需向搜索引擎提交个人姓名、号码、订单号或完整原文。
2. 先读主管机关的发布原文，再补地方实案。按发布日期检索到当天，同时保留历史上能说明机制的记录。搜到转载时追溯原发布，同源转载只算一条。只有标题或摘要可见时注明这一限制；热线、时限和具体办事流程需从能打开的官方页面核实。
3. 记录“场景与别名｜地区｜原发布者与标题｜发布日期／案发时间（若已披露）｜对方要求的动作｜用户能独立核对什么｜止损入口｜原文链接｜核验日期”。缺项填“未披露”。按身份、资金或权限动作、核验路径比较，只有名称变更时并入旧条目的别名；确实改变核验和处置方法时再加一行。
4. 用户要求**更新技能**时，将有来源的变化写回类型索引或处置指引，更新相应核验日期与覆盖说明，检查引用和文件链接。若只问“最近有什么”，在回复中给出查新结果，不改技能。无法联网时使用有日期的存量材料，说明待查事项。
5. 给结论配支持该结论的直接链接。单案能证明一种手段在某地发生过；要说“高发”则需有时间与地区一致的统计或官方声明。即使检索不到某个账号，也不能据此为其背书。

**查新条目示例**  
广东江门，2026-11-01 发生，11-19 通报。以逾期“律师函”要求扫码，再以处理征信为由要求转钱刷流水。归入“贷款、征信”，补充别名“扫码律师函”。独立核验路径为原借款应用账单和机构公开电话。核验于 2026-11-21。[江门市公安局原文](https://www.jiangmen.gov.cn/bmpd/jmsgaj/zwgk/sjfb/content/post_3588792.html)
