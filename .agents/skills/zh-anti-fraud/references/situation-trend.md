# 做局的流程与风向

用这个参考回答“这事走到哪一步”“为什么突然变了”“他接下来可能做什么”。阶段只是整理故事的方法，可以跳过、重叠或退回。普通办事也会经过介绍、协商和签约。判断要靠条件和证据，尤其是原先可讨论的事是否变成必须马上承担的义务。

用户想讲每一步的感受时，用[阶段复盘](stage-recap.md)把当时能知道的事实和后来才知道的情况放回各自时点。

| 可能走到这一步 | 已经能看见什么 | 此刻能做什么 |
|---|---|---|
| **接触与看需求** | 找到联系理由，问意向、难处或能否帮忙，尚无明确交换 | 在回答前问清谁发起、要谈哪件事、与自己有什么关系 |
| **借关系与背书** | 原有熟人牵线，出现领导、专家、机构或多人附和的说法 | 检查每条背书的原始来源，用独立渠道核身份和授权 |
| **小请求与口头答应** | 帮转发、到场、代问、垫小笔，或随口说“我可以看看” | 写明同意范围，及时纠正别人把答复扩大成承诺 |
| **改变条件与要求落地** | 从群聊转私聊，从单位账户转个人收款，从协助变个人签名，从可商量变成限时 | 比较前后两版。暂停新增付款、署名、签字、交件或授权，只回到能够独立核实的流程 |
| **催办与限制核验** | 对方压缩截止时间，阻碍回拨，要求保密，换人重复同一要求，或以关系后果施压 | 写清对方催促的动作。可撤回的时点已经明确时，一并写出。让有权确认的人独立核实。涉及人身、资金或设备时先处理暴露情况 |
| **兑现、持续索取或事后改口** | 已交款、已署名、已给权限或已代办。承诺可能兑现，也可能追加条件、拖延、变更口径或转移责任 | 对照约定与已发生的结果，核对责任和证据。尚可撤销的授权先撤销。已出现损失或冒用时使用[止损与证据](response.md) |

## 怎么判断风向

- **以最近一次具体变化为依据。** 上回答应周五书面确认，这次改成今晚个人账户付款，期限和渠道同时变了。对方今天态度变冷，手续和交易条件仍然相同，只能记录态度变化。
- **缓和有可对照的迹象。** 对方接受暂停和独立核验，正式负责人确认权限，书面条件与实际要做的事一致。熟悉的供应商换账户，经原合同号码回拨确认、按程序补签和审批，这些新增证据可以降低该项风险。
- **转向时说明代价换到了哪里。** 例如一开始想让用户出钱，在用户拒绝后改为要求借出名字。钱暂时保住了，声誉和责任变为新的决定点。收到对方口头改口时，要再查已有转账、签字或授权是否已经撤回。
- **给预判写触发条件。** 选两三种有事实支持的后续。若过期后对方仍接受原合同渠道，新证据支持日常催单解释。若坚持个人收款且拦着用户核验，暂停的依据更强。只有一个时间点，就说明暂时看不到变化，并点出接下来值得观察的动作。
- **用户补充消息后重新定位。** 从上一轮结论选一条已说过的观察条件，列出之前、现在和对下一步的影响。如果新证据推翻旧判断，直接更新。若事情已经恢复正常流程，可说明哪些动作可以照常办，哪些仍需完成核验。

**虚构示例。** 甲牵线、乙催单、丙给收款码。三人转发同一张“领导同意”的截图。用户说要核实后，原来的“这周答复”变成“今晚打到个人账户，先别向领导问”。可以明确的是谁引荐、谁催、谁给收款码，而三份截图只提供一个出处。风向升温依据是期限缩短、改用个人账户、限制核验。先停在付款前，通过原合同、单位正式窗口或原采购联系人核对。若正式渠道确认真实业务和单位账户，核验后的业务仍可继续。若否认订单或确认该账户无权收款，保存现有记录并中止支付。
