# 社会第一课

用户说“我刚出来”“教我社会第一课”或“社会上有哪些坑”时，默认从常见生活场景开始。先用一个贴近他处境的例子，讲清哪句话看着合理、什么动作让风险变大、去哪里核对，再给一句他用得上的回复。用户想系统学时，按下表往下练。若他已经遇到具体的事，先处理眼前的决定。

## 按经历和责任来学

| 使用者面对的决定 | 从哪几课开始 | 学会以后能做什么 |
|---|---|---|
| **初入社会，第一次自己签约或付钱** | 求职试岗、租房押金、借账号、熟人介绍、陌生客服 | 看懂自己以什么身份签字、钱交给谁、谁有权兑现，以及怎样开口暂停 |
| **在职、负责具体工作或有合作经验** | 口头承诺被扩大、项目抢功甩责、人情逼表态、前辈提携与夸口 | 分辨“谁代表发言”和“谁做了事”，把任务范围、决定和交付写清楚。发现条件变动时，留住有用的合作 |
| **带人、做生意、管预算或有签批责任** | 假借上级授权、熟人要求破例、收款账户变更、先垫货后补手续、利益冲突 | 查谁真有权决定、谁会获益、谁最后担责。按原渠道核验，在权限内保住项目进度和交易选择 |

同一个人可以跨着学。熟悉单位流程的人可能是第一次租房，刚创业的人可能有多年带团队经验。用他眼前会遇到的决定来定难度。

## 常见场景与第一步

| 场景 | 当事人该先看什么 | 可以怎么回 |
|---|---|---|
| **求职、试岗、培训** | 招聘是谁发的？试做为什么要用你自己的身份或账户收钱？签的是工作协议、培训协议还是个人借款？ | “请把岗位、试做内容和费用用正式渠道发我。我的个人账户先不用来收款。” [招聘风险提示入口](update.md) |
| **租房、二手交易、熟人借用名义** | 房源和收钱的人谁能独立确认？转钱在看房、核身份和写清退款条件以前还是以后？谁要借用你的信用或账号？ | “我先看房、核对出租授权，再谈押金。我的账户不代收、不代转。” [生活和跨境场景](patterns.md) |
| **代签、入职文件、朋友请担保** | 是签收还是承认债务？你以个人、经手人还是公司代表的身份签？空白金额和附件是谁来填？ | “我可以确认收到文件。若要我承担个人责任，请先给我完整正文。” [签字核对](story-analysis.md) |
| **同事抢功、口头安排、被推去担责** | 谁实际做了事，谁负责对外汇报？正式版本和审批记录怎么写？是正常分工还是有人把责任推给你？ | “我负责的是这部分，最终决定由谁确认，麻烦补进纪要。” [人情场怎么回](social-dynamics.md) |
| **前辈带路、熟人担保、饭局站队** | 过去的帮助已经兑现了什么？新要求要你先交什么？你能不能见到真正有决定权的人？ | “之前的帮助我记着。这次请让我和正式负责人核一下，我看完再答复。” [辨别提携、夸口和设局](mentor-assessment.md) |
| **经营、审批与跨团队合作** | 关系、项目和权限要分别核实。“领导答应了”是谁说的？账户变更由谁授权？交易失败谁承担？ | “订单照常核对。变更请走原合同或单位流程，我会向有权确认的人复核。” [涉及公权力的公开案例](authority-cases.md) |
| **客服电话、投资与海外常见骗局** | 原本说退款、挣钱或协查，后来为何索密码、共享、交钱、寄实物或要求保密？当前有哪一步仍能停住？ | “我从原订单、银行卡背面的电话或当地官方入口自己确认。” [国内类型](patterns.md) · [海外类型](global-scams.md) · [已经受损怎么办](response.md) |

## 把一课练到能用

1. 用一句话说清楚一个虚构场景的转折。例如“本来是应聘客服，后来变成要我用自己的账户替别人收款”。
2. 让当事人亲自说出首先能守住什么、该找谁独立核实、怎样回复。可以先让对方试答，再按需补充。他若只想看一份直接可用的答案，就给示范。
3. 给一条新的事实练习改判断。例如公司证实岗位存在，但否认用个人账户试岗。岗位真实与试岗要求是否获得授权要分别判断。
4. 需要复盘时，加上当时的感受。有兴奋、感激、犹豫或怕机会没了，都可以按原话放回时间线，再看后续证据如何改变行动。[阶段复盘](stage-recap.md)

练过之后，用户应能自己问出四件事：**我原来答应了什么？现在要我交出什么？凭什么相信对方有权限？我还有什么办法保住选择？** 可选一则贴切的典故帮助记住这个转折。[典故索引](allusions.md)
