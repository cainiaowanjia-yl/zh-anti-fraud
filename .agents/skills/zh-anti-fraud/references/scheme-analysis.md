# 做局分析

用户讲亲身经历时，先说他最值得守住什么。要做不可逆的付款、签字、交证件、给权限或对外表态时，优先保护他暂停和独立核验的权利。有真实退款、交货、申诉或求职时限时，同时告诉他可以走哪条已核实的途径保住机会。[先守住自己的利益](own-interests.md)

故事有多个转折，或用户要找做局点、看心理如何被影响、问对方想得到什么时，按[做局深拆](deep-analysis.md)逐点分析。这里保留快速分析、证据对照和分层讲法。

## 还原那一步怎么变的

| 用当事人的话来问 | 分析里要写清的东西 |
|---|---|
| 最早说要办什么，我为什么相信？ | 记原话和当时能接触到的信息。后来的消息另排时点，感受按用户自述 |
| 谁接了谁的话，谁有权拍板？ | 分开引荐、转述、施压、执行和批准。被人提到的上级、在场的熟人、被指定的收款人都按实际动作来写。多人传一张截图仍只有一个消息源 |
| 哪里改了条件，我当时能拒绝吗？ | 对照原条件和后来要求。常见变化有从口头变签字、从单位变个人、从咨询变担保、从自愿变限时、从明面办理变成私下核验 |
| 谁得到什么，谁承担什么？ | 沿钱、署名、决策权、时间、工作成果、声誉和责任看去向。分别注明已经发生的结果与可能发生的结果 |
| 下一步怎么做才守得住？ | 给一个能当场执行的动作、一个独立核验渠道、一句可用的话。再用具体的“如果”说明何时可以继续、何时暂停或退出 |

## 同时考虑几种解释

| 可能发生了什么 | 哪些证据更能区分 |
|---|---|
| **事前有意安排** | 事前记录、正式调查或独立核实的材料能显示此前已虚构关键前提、约定分工或安排利益。只看到好几个人依次说话，仍需核实他们有没有共同指令 |
| **原事属实，中途才有人占便宜** | 原项目、主张或关系可以查实，后面才增加私下收费、改签职责或扩大口头承诺。查新要求是谁提出的，对方知道原范围之后有没有纠正 |
| **流程变化、能力或权限不足** | 从原单位或原渠道查到为什么会变，能否纠正。有人说“包成”但只能帮忙转达，就指出他夸大了哪一项，按这项能力评估 |
| **有利益冲突、也出了差错** | 可能同时有流程疏漏和一方获利。分别核查谁掌握了哪些信息、利益有无披露、发现问题后继续了什么。事情紧急时，意图可以待查，先决定自己的钱、名义和职责如何处理 |

判断可写“目前看得清的是新要求超出了原约定。谁有意安排这一点还待核实”。然后给**最能区分解释的一项核查**，例如从原合同电话找到真正有权确认的人。把那个结果如何改变下一步讲清楚。查到正常解释时，把结论也改回来。

## 同一个故事，按三种经历来讲

**虚构故事。** 学姐介绍一个客服岗位。面试时说能直接上岗，之后面试人改口要求交培训费，第三方发来一份以求职者名义签的分期协议，承诺上岗后报销，并要求当天签。

- **刚入社会。** 你眼下要决定的是借不借这笔钱。先停在签字前，从用人单位公开渠道核岗位和培训条件。可以回“我先看合同，今天不签分期。录用和报销请由用人单位书面确认”。
- **有工作经验。** 岗位推荐、录用决定、培训收费是不同节点。学姐完成了介绍，面试人改变条件，第三方递来分期。是否知情要分别核验。若官方确认岗位存在，却否认这个培训要求，可以继续核原岗位，同时暂停分期。
- **负责用人或经营。** 查用人主体、培训机构和资金提供方各自书面承担什么。核实谁作出了报销承诺、谁能批准、谁实际收费用。可保留招聘记录和协议，用原人事渠道核实并纠正对外承诺。在权限内处理情况，相关费用和外部款项分别核验。[招聘风险与公开来源](update.md)

如果用户想知道“下一步还会怎么变”，只在故事有依据时给两三条分支，并和可执行的动作配在一起。[流程与风向](situation-trend.md)
