# 社会第一课

**社会第一课**是一项中文 Codex 技能。讲一段求职、职场、生意或人际经历，它会和你一起梳理事情何时变了条件、谁做了什么、你要承担什么，以及下一步怎么守住自己的钱、时间和选择。

## 简介

- **刚入社会**可以从求职、租房、签字和熟人介绍里的常见陷阱学起。
- **在职、做生意或负责签批**可以逐段拆解人情压力、改口推责和托关系办事。每一步都有可执行的核验和应对办法。
- **想快速听懂整件事**可以用大白话模式。也可以请技能用典故解释某个节点，或根据公开反诈案例查相似做法。

## 在 Codex 中使用

将仓库克隆到本地，然后用 Codex 打开仓库目录。项目技能位于 [`.agents/skills/zh-anti-fraud`](.agents/skills/zh-anti-fraud/SKILL.md)。在聊天里输入以下内容，再接着讲自己的经历。

> 用 $zh-anti-fraud 给我上一堂社会第一课。我刚开始工作，请用一个例子教我怎么发现条件变了、怎么独立去核实、怎么开口留住自己的选择。

也可以直接讲一件事，请技能做局分析，判断事情什么时候转向、谁在接力、最后由谁承担代价。可用甲、乙等代称。仓库附有典故、国内外公开诈骗案例和止损指引。

想听大白话，可以说“用 ELI5 从头给我讲一遍”。说“ELT5”也会进入这个模式。
